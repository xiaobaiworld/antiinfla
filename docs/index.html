Brand story

不是“功能轰炸”，而是“舒服地介绍产品”。

视觉语气

采用米白、浅杏、橄榄绿和柔和棕色，营造温暖、安定、可亲近的气质，让页面像一张安静的产品手册。

内容重点

更适合讲清楚食材来源、口味体验、适合人群、食用方式，而不是堆叠过强的营销术语。

上线方式

页面文件放在仓库的 /docs 目录，之后在 GitHub 仓库设置里开启 Pages 即可公开访问。

Product directions

轻食零嘴

少负担的小零食

适合介绍坚果、冻干水果、低糖饼干、烘焙谷物片等产品，强调口感与陪伴感。

冲饮谷物

早餐和下午的温热选择

适合展示燕麦饮、谷物粉、代餐杯或轻养生饮品，突出方便、饱腹和柔和风味。

草本茶饮

更偏日常节奏的饮用型产品

可以放花草茶、红枣茶、桂圆茶、无咖啡因配方等内容，重点放在场景和饮用感受。

Daily rhythm

让页面不只是“卖东西”，也给人使用场景。

一个舒服的健康产品网站，通常不需要写得太满。可以用“早晨轻食”“午后热饮”“晚间舒缓”这种方式来组织内容，让产品和生活节奏自然连接。

这样做的好处是，网站会更像陪伴式介绍，而不是生硬陈列，整体观感也更有温度。

FAQ

先把最常被问到的说明放在首页。

这个网站是否需要后端？

不需要。当前版本是纯静态页面，只包含 HTML、CSS 和少量原生 JavaScript。

是否可以直接发布到 GitHub 上？

可以。当前页面已经按 GitHub Pages 适配，推荐从 main 分支的 /docs 目录发布。

后续还能继续扩展更多页面吗？

可以。你只要继续在 /docs 里增加新的 HTML 文件，GitHub Pages 会按目录结构继续公开这些页面。
