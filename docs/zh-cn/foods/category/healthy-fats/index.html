抗炎健康脂肪

健康脂肪能让餐食更满足、更完整。本页关注适合烹饪、调味和简单家庭餐的选择。

这个分类里的食物

橄榄油适合调味、平底锅烹饪和简单家庭料理的日常基础。
牛油果油当你需要适合较高温烹饪的油时，它很实用。

为什么健康脂肪能让餐食更好吃

健康脂肪能让日常饭菜更好吃、更有满足感。这个分类关注的是适合烹饪、调味、碗餐和简单家庭餐的选择。

如果一餐看起来已经健康，但吃起来仍然有点单薄，脂肪往往是最容易调整的地方。改变烹饪用油或餐后淋一点油，就可能让好习惯更容易重复。

如何选择健康脂肪

健康脂肪最实用的地方，是帮助你更愿意吃完整食物。橄榄油可以让蔬菜、豆类、谷物和沙拉更好入口。牛油果油适合需要中性味道、又要较高温烹饪的时候。

你不需要一次准备很多种油。大多数厨房可以先用一种适合调味和温和烹饪的日常用油；只有当它真的解决某个烹饪问题时，再增加另一种。

健康脂肪的简单用法

  • 用橄榄油搭配蔬菜、豆类、扁豆、藜麦、番茄和香草。
  • 想要更中性的味道时，用牛油果油来烤或平底锅烹饪。
  • 把脂肪和高纤维食物搭配，让一餐更有饱足感，也更均衡。
  • 用橄榄油、柠檬、大蒜、香草和少量盐，快速调一个简单酱汁。

需要注意什么

健康脂肪仍然热量较高，所以不是越多越好。目标是替代不太适合的脂肪，并让完整食物更容易吃下去，而不是每一餐都额外倒很多油。油类也要避开高温和强光存放，并留意新鲜度。
