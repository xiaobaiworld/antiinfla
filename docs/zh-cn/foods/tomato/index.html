番茄

番茄可以生吃，也可以熟吃，能提供番茄红素、维生素 C 和鲜味，很适合加入日常抗炎饮食。

快速回答

番茄提供番茄红素、维生素 C、钾和鲜味。熟番茄和橄榄油搭配时，番茄红素更容易被吸收，很适合日常抗炎餐食。

它是什么

番茄是常见水果型蔬菜，既可以生吃，也可以熟吃。常见形式包括新鲜番茄、罐装番茄、番茄酱和番茄膏。

它在地中海风味和许多家常菜中都很常见，适合沙拉、汤、炖菜、酱汁和碗餐。

为什么番茄可能支持抗炎饮食

番茄最被关注的是番茄红素，这是一种类胡萝卜素。熟番茄搭配油脂时，番茄红素吸收通常更好。

番茄也提供维生素 C、钾和鲜味，可以让简单餐食更有层次。

关键营养和化合物

番茄提供番茄红素、维生素 C、钾和多种植物化合物。熟番茄制品番茄红素更集中，但钠和添加糖需要注意。

潜在健康益处

  • 提供番茄红素。
  • 生吃和熟吃都容易。
  • 和橄榄油搭配有助于脂溶性营养吸收。
  • 增加餐食鲜味，帮助减少重调味依赖。
  • 适合沙拉、汤、酱汁和碗餐。

番茄怎么吃

  • 新鲜番茄配罗勒、橄榄油和一点盐。
  • 用番茄、大蒜和橄榄油做简单酱汁。
  • 加入鹰嘴豆、扁豆或藜麦碗。
  • 用罐装番茄做汤和炖菜。
  • 和沙丁鱼或三文鱼搭配。

购买和储存

新鲜番茄成熟后室温短期保存风味更好，切开后冷藏。罐装番茄和番茄膏适合储藏，但要注意钠和添加糖。

FAQ

番茄抗炎吗？

番茄提供番茄红素、维生素 C 和其他植物化合物，适合抗炎饮食方式。

熟番茄比生番茄好吗？

熟番茄中的番茄红素通常更容易吸收，生番茄也有维生素 C 和清爽口感。两者都好。

番茄适合和什么搭配？

橄榄油、大蒜、罗勒、豆类、鱼类、全谷物和绿叶菜都很适合。

番茄酱健康吗？

简单番茄酱可以很好，注意添加糖和钠。

证据说明

关于番茄的研究通常关注营养组成、植物化合物和整体饮食习惯。

本页将番茄作为抗炎饮食中可以辅助搭配的一种食物来介绍，而不是把它作为单独的治疗方法。
