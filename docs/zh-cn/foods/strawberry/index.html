草莓

草莓是常见浆果，可以给简单餐食增加甜味、维生素 C 和抗氧化多样性。它适合抗炎饮食方式，因为很容易在早餐和零食中反复使用。

快速回答

草莓提供鞣花酸、花青素，以及相对于热量来说很高的维生素 C。它是日常抗炎饮食里最容易获得的浆果之一，因为购买方便、用法灵活。

它是什么

草莓是 Fragaria 属的红色浆果，在世界温带地区广泛种植。它有新鲜、冷冻、冻干和果酱等形式。

草莓可以直接作为零食，也可以切片放进谷物、沙拉和酸奶里，或打进奶昔和做成甜点。冷冻草莓多数营养能较好保留，也更容易全年使用。

为什么草莓可能支持抗炎饮食

草莓含有花青素和鞣花酸，这些成分因抗氧化和抗炎相关特性受到研究关注。花青素也与氧化压力和炎症相关基因表达研究有关。

草莓的维生素 C 含量也很高。维生素 C 是重要抗氧化营养素，并参与免疫功能和胶原合成。草莓中的纤维也能通过肠道健康支持整体饮食质量。

关键营养和化合物

一份 100 克生草莓提供较多维生素 C、少量纤维、叶酸、钾和锰，热量较低。花青素含量会因品种、成熟度和储存方式不同而变化。

潜在健康益处

  • 相对于热量，维生素 C 含量较高。
  • 含有鞣花酸和花青素等被研究的植物化合物。
  • 纤维有助于支持肠道健康。
  • 升糖负荷相对温和，适合注意血糖的人谨慎搭配。
  • 适合日常早餐、零食和简单甜点。

草莓怎么吃

  • 把新鲜草莓切片放在燕麦、酸奶或隔夜燕麦上。
  • 把冷冻草莓和菠菜、奇亚籽一起打进奶昔。
  • 切丁后加入谷物沙拉，搭配坚果和香醋。
  • 直接整颗当作无需准备的便携零食。
  • 用草莓、红洋葱、香菜和青柠做简单莎莎。
  • 冻干或烘干后作为更耐储存的零食。

购买和储存

选择颜色鲜红、结实、有香气的草莓。避免有白尖、软斑或发霉的果实。未清洗时冷藏保存，并尽量在 3 到 5 天内食用。冷冻草莓通常在成熟度较好时采摘并冷冻，是很实用的选择。

FAQ

冷冻草莓和新鲜草莓一样有营养吗？

通常可以。冷冻草莓多在成熟时采摘并快速冷冻，能较好保留维生素 C 和多酚。

草莓一定要买有机吗？

草莓常出现在农残关注列表中，充分清洗会有帮助。不过，不论种植方式，吃草莓带来的营养价值通常仍值得考虑。

每天应该吃多少草莓？

没有严格要求。即使每周吃几次一小把，也能增加多酚和维生素 C 摄入。

草莓能帮助关节炎症吗？

一些观察研究把较高浆果摄入与较低炎症标志物联系起来，但草莓应被看作整体饮食习惯的一部分，而不是针对性治疗。

证据说明

草莓多酚研究包括控制喂养研究和流行病学数据。一些临床试验关注冻干草莓粉对炎症标志物和血脂指标的影响，结果显示可能有温和改善。

本页将草莓作为抗炎饮食中可以辅助搭配的一种食物来介绍，而不是把它作为单独的治疗方法。
